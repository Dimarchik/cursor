# Снайпер мемкоинов на pump.fun: «вернуть вложенное → держать остаток»

- `RESEARCH.md` — ресерч: какая сеть, какие боты на GitHub, экономика.
- `bot/` — бот [chainstacklabs/pumpfun-bonkfun-bot](https://github.com/chainstacklabs/pumpfun-bonkfun-bot) (Apache 2.0) с добавленной стратегией `recover_and_hold`. Что изменено — в `bot/NOTICE`.

## Как работает стратегия

1. Бот слушает Solana и ловит создание новой монеты на pump.fun.
2. Покупает её на `buy_amount` SOL.
3. Каждые 2 секунды проверяет цену. Когда она выросла в `recover_multiplier` раз (по умолчанию в 2 раза), продаёт часть, чтобы вернуть вложенное плюс 5% на комиссии. На 2x это 52.5% монет.
4. Остаток держит и больше не продаёт. Запись о нём попадает в `bot/trades/moonbags.jsonl`.
5. Пока монеты ждут роста, бот покупает новые (до `max_open_positions` одновременно).
6. Если за `max_hold_time` (по умолчанию 30 минут) цена так и не выросла в 2 раза, бот продаёт всё (`sell_all`) и возвращает залог за аккаунт. Можно поставить `hold` — тогда он ничего не продаёт и держит.

Все настройки с комментариями на русском: `bot/bots/bot-recover-and-hold.yaml`.

## Запуск

Нужно: Linux/macOS (или WSL), Python 3.11+, [uv](https://github.com/astral-sh/uv).

```bash
cd bot
uv sync
uv pip install -e .
cp .env.example .env    # заполнить .env (см. ниже)
```

В `.env`:
- `SOLANA_NODE_RPC_ENDPOINT` и `SOLANA_NODE_WSS_ENDPOINT` — адреса от RPC-провайдера (Chainstack, Helius, QuickNode; есть бесплатные тарифы). Публичный RPC Solana не подойдёт.
- `SOLANA_PRIVATE_KEY` — приватный ключ **отдельного нового кошелька** только для бота. Не основного!

Остальные боты в `bot/bots/` выключены (`enabled: false`), работает только `bot-recover-and-hold`.

```bash
pump_bot                       # запустить; логи в bot/logs/
uv run tools/moonbags.py       # баланс кошелька и стоимость монет в холде
```

Остановить бота: Ctrl+C. Позиции, которые ещё ждали роста, останутся в кошельке и запишутся в `moonbags.jsonl` с пометкой `shutdown`.

## Деньги

- На каждую купленную монету сеть берёт залог **~0.002 SOL** за токен-аккаунт. При полной продаже он возвращается. Пока держишь остаток, залог лежит в аккаунте.
- Поэтому рекомендуемый тест — **0.1–0.2 SOL** на кошельке и `buy_amount: 0.005`. С $1 бот успеет открыть всего 3–4 позиции.
- Подробности и статистика (большинство монет умирают в первый же день) — в `RESEARCH.md`.
